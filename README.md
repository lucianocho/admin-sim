# 행정과정 시뮬레이션

사이드바에서 시나리오를 고른다.

- **키를 입력하지 않으면** 세 시나리오 모두 시연(예시 재생) 모드로 동작한다. AI를 호출하지 않는다.
- **사이드바 "실시간 AI 설정"에 Claude API 키를 입력하면** 그 브라우저 창에서만 실시간 모드가 켜진다.
  - 키는 서버 파일이나 저장소에 기록되지 않고, 창을 닫거나 새로 고치면 사라진다.
  - 다른 사람이 같은 주소로 접속해도 키가 없으므로 시연 모드로만 보인다.
  - 기본 모델은 `claude-opus-5-5`이며 사이드바에서 바꿀 수 있다.

## 시나리오

- 공공재정관리 · 박물관 신축 예산 설득
- 전략관리 · 고용보험–국세청 소득정보 연계 협상
- 전략관리 · 애로우 불가능성 정리 시연 (실시간 모드에서는 AI가 선호를 생성)

## 실행

```
pip install -r requirements.txt
python -m streamlit run app.py
```

## 배포

깃허브 저장소에 이 폴더의 파일을 올리고 share.streamlit.io에서 `app.py`를 지정한다. Secrets는 비워 둔다.
